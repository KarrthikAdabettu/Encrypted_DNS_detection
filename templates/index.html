// 03 — Model Accuracy Comparison
We tested 5 different machine learning algorithms on both layers. Each model reads the same CSV rows and learns to classify them using packet statistics only — no packet contents. Layer 1 is generally easier because DoH and non-DoH traffic are statistically very different. Layer 2 is harder because malicious DoH is specifically designed to mimic normal DoH — the model must find subtle differences. 5-Fold CV shows how reliably the model generalises to completely new data — close to the accuracy score means the model is not memorising the training data.

// 04 — Best Model — Confusion Matrix & Metrics
The confusion matrix shows exactly what the model got right and wrong on individual flows. True Positive = malicious flow correctly caught ✅. True Negative = benign flow correctly cleared ✅. False Positive = benign flow wrongly flagged as malicious ❌ — innocent user affected. False Negative = malicious flow wrongly cleared as benign ❌ — attacker gets through. This is the most dangerous error in security. Recall on Malicious = out of all real attacks, how many did we catch? We want this as high as possible.
